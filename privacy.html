Freelance Ledger is a static website. There are no accounts and we do not sell personal data.

Hosting logs

The site is hosted on GitHub Pages. GitHub may log standard server data (such as IP address, browser, and pages requested) for security and operations. See GitHub's Privacy Statement.

Calculators and the invoice generator

The calculators and the invoice generator run entirely in your browser. What you type is not sent to us or stored by us. Closing the tab clears it.

The newsletter is not active yet. When it is, we will name the email provider on this page before any signup form appears, and we will use your address only to send the newsletter. You will be able to unsubscribe from any email.

Analytics

This site uses Cloudflare Web Analytics, a privacy-friendly service that measures visits without cookies or tracking individuals.
